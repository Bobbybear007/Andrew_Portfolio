Inscribe

A simple writing environment for people who want to focus and keep control of their files. It works like a digital notebook with Markdown support and manual saving directly to your computer.

Use Inscribe
Type: Writing Tool
Focus: Local-First + Privacy
Stack: HTML / CSS / JavaScript
Status: Active

Overview

Inscribe started with a simple problem: my documents were filling up Google Drive while I had plenty of local storage. I wanted something like Google Docs without the cloud storage or data collection. The result is a local-first writing tool where I stay in control of my files.

The tool gives you a clean place to write without requiring an account or a cloud connection. Everything stays on your device and manual save controls mean you decide when and where your work is stored.

Problem Statement

While working on projects I realised that a lot of my documents were filling up Google Drive. I had plenty of space on my hard drives, so I thought a Google Docs-like site that only needed to know where I wanted to save files would be useful.

Design & Development

Inscribe was built to be quick, simple and predictable. It runs entirely in the browser and avoids external dependencies and cloud integrations.

Tech Stack

  • HTML, CSS, JavaScript - No frameworks. The app is browser-based and easy to move between devices.
  • File APIs - Open, edit and save `.docx` or `.pdf` files locally.
  • Custom Save Logic - Save and download buttons instead of autosaving or background storage.

Design Philosophy

Inscribe is meant to stay out of the way. The interface is clean and a little retro, with the focus kept on the text rather than on extra features.

Accessibility Focus

  • Semantic HTML with keyboard-friendly navigation.
  • Clear, legible type with responsive layouts.
  • Designed to work without reliance on themes or system preferences like dark mode.

User Testing

User feedback helped shape clean file exports and editable titles. The tool should feel fluid without doing anything surprising, so nothing is saved unless you choose to save it.

Key Features

Local-Only

All writing takes place in the browser. Nothing is stored online or auto-saved. Users are responsible for saving their work to disk.

Manual Save & Open

Load `.docx` files, export as `.docx` or `.pdf` and save edits using native browser file dialogs. No sign-in, no upload and no cloud.

Minimal UI

A clean writing interface with no sidebar, no menus and no distractions. Just you and your words.

Markdown Support

Supports standard Markdown syntax with a toggleable live preview, allowing users to format documents cleanly and efficiently.

Portable & Lightweight

No installation required. Just open the page and start writing. Works entirely in-browser on desktop or laptop devices.

Final Result

Inscribe provides a fast, no-nonsense writing experience for people who value autonomy over convenience. It avoids the noise of modern apps and gives control back to the user, with full ownership of their work.
